# 🐍 Python OOP Programs

> A collection of **Object Oriented Programming** examples built with Python 3

---

## 📌 Programs Included

| # | Program | Description |
|---|---------|-------------|
| 1 | 🧑‍💻 **Programmer Class** | Shows programmer company & product info |
| 2 | 🔢 **Calculator Class** | Computes Square, Square Root & Cube |
| 3 | 📝 **Sample Class** | Demonstrates class variables |
| 4 | 👨‍💼 **Employee Class** | Manages employee names & salaries |

---

## 🚀 What is OOP?

```
OOP = Object Oriented Programming
         ↓
Real world things → Classes
         ↓
Classes create → Objects
         ↓
Objects have → Properties & Methods
```

## 🧠 Concepts Covered

| Concept | Explanation |
|---------|-------------|
| 🏗️ **Class** | Blueprint for objects |
| 🔧 **__init__** | Constructor method |
| 📦 **self** | Refers to current object |
| 🔄 **Methods** | Functions inside class |
| 📊 **Class Variables** | Shared by all objects |
| 👤 **Instance Variables** | Unique to each object |
